# 오디오 처리

마이크가 기록하는 혼합 파형은 같은 시점에서 두 화자와 주변 소리의 샘플이 더해진 값이다. 두 사람의 기본 주파수와 배음이 시시각각 바뀌므로 대역 필터만으로 한 화자의 발화를 골라낼 수 없다. VoiceFocus는 등록 음성과 함께 파형을 모델에 전달해 목표 화자의 음성을 추정한다.

- **입력**은 최대 8채널, 8–192 kHz WAV를 읽는다. 채널을 평균해 모노로 만들고 다상 FIR 필터로 16 kHz에 리샘플링한다. 무음, 손상된 파일, 범위 밖 샘플은 입력 오류로 처리한다.
- **실험 혼합**은 앞 음성이 끝나기 전 뒤 음성을 시작하도록 시차를 두고, 활성 구간의 RMS를 기준으로 상대 게인을 설정한다. 오버랩은 혼합 전 같은 길이로 자른 음성 구간의 겹침 비율이다. 클리핑을 피하기 위해 정답 음성과 간섭음, 혼합에 같은 스케일을 적용한다.
- **등록 샘플**은 각 화자의 0번 발화이며 혼합에 쓰는 1–5번 발화와 독립적이다. 합성 음성은 각 화자가 같은 문장을 읽게 하고 등록에는 혼합에 없는 문장을 쓴다.
- **시각화**는 같은 진폭 범위에서 파형을 표시한다. 스펙트로그램은 16 kHz에서 512샘플 Hann 창으로 계산한 STFT를 두 결과 모두 같은 dBFS 범위에 매핑한다. 브라우저에서는 화면 폭에 맞춰 시간축을 다운샘플링한다.
- **평가**는 정렬된 참조 파형에 대해 SI-SDR을 계산하고 혼합의 SI-SDR을 빼서 개선량을 구한다. 목표가 침묵한 경우 에너지 비율로 누설을 보고하며, 청취용 PCM은 클리핑이 없도록 필요할 때만 감쇠한다.
