# VoiceFocus 제품 요구사항

카페나 교실처럼 여러 사람이 말하는 환경에서, 짧게 등록한 사람의 발화를 혼합 음성에서 추정한다. 단일 마이크 신호에서 목표 화자의 등록 음성을 조건으로 쓰는 Target Speaker Extraction을 적용한다.

## 파일 데모

- 두 WAV를 16 kHz 모노로 변환하고 시작점을 맞춰 혼합한다. 결과는 재생, 파형, 스펙트로그램, 다운로드로 확인한다.
- 혼합 WAV와 별도의 등록 WAV를 받아 목표 화자를 추출한다. 같은 혼합에서 A 또는 B의 등록 음성을 사용해 대상을 바꿀 수 있다.
- 원본과 추정 음성을 비교하고 다운로드한다. 모델 이름과 버전, 전체 처리 시간과 모델 추론 시간을 제공한다.
- WAV 형식, 크기, 길이, 무음을 검사한다. 서버의 음성과 작업 정보에는 임시 보관과 만료 정책을 적용한다.

사전 학습 모델로 최소 두 화자의 동시 발화에서 A/B 선택을 검증해야 파일 데모를 완료로 판단한다. 재현 가능한 혼합과 독립 등록 샘플, 분리 지표, 실패 조건, 청취용 비교 파일을 함께 남긴다.

## 단계별 범위

| 단계 | 기능 | 판단 기준 |
| --- | --- | --- |
| 파일 데모 | WAV 합성, 등록, 추출, 비교 | 실제 추론 결과가 등록 선택에 따라 달라지고 업로드부터 재생까지 동작 |
| 스트리밍 연구 | 모델 처리 속도와 청크 지연 측정 | RTF 0.5 미만과 추가 지연 100 ms 미만을 목표로 평가 |
| 마이크 실시간 | 장치 선택, 수준·지연 표시, AudioWorklet과 WebSocket | 상태를 유지하는 모델로 안정적인 출력 확인 |
| 자체 통화 | WebRTC 방, 상대 화자 등록, 적용 전환, 지연·음질 모드 | 스트리밍 기준을 통과하고 두 기기에서 음성 재생 검증 |

현재 측정에서는 스트리밍 기준을 충족하지 못했다. 일반 전화 앱과 타사 메신저의 통화 오디오 연동은 초기 범위에서 제외한다.
